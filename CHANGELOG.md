# Changelog

What changed between releases, in the changes you will notice. Not every fix is listed.

## 0.9 (alpha)

The first public release.

- Watchlist and season calendar from AniList and Kitsu, with release profiles per anime
- RSS feeds and indexer search with auditable matching, handed to qBittorrent, Deluge or Transmission
- Import by copy, move or hardlink; standalone, or hand-over to Shoko Server
- Setup wizard with a notice to accept first; English and German
- Covers are fetched by AniFlow, so metadata providers never see your browser
